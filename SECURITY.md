# Security Policy

## Reporting Security Issues

We take the security of `ai-policy-kit` seriously. Because this project provides automated validation tools and GitHub Actions that execute in repository CI pipelines, security and deterministic behavior are paramount.

If you believe you have found a security vulnerability, please do NOT open a public issue.

Instead, please report it responsibly by emailing:
**trieunt7@gmail.com**

Please include:
* A description of the issue / vulnerability.
* Steps to reproduce or proof-of-concept.
* Potential impact.

We will acknowledge receipt within 48 hours and work on a fix as soon as possible.
