Initial release of `ai-policy-kit` v1.0.0:
- Declarative AI contribution policy validation conforming to JSON Schema Draft-07 (`schema/v0.1/ai-policy.schema.json`).
- CLI tool suite (`init`, `check`, `lint-pr`) for local developer workflows and continuous integration.
- Self-contained GitHub Action (`action.yml`) with automated step summary reporting.
- Built-in policy presets (`strict`, `balanced`, `permissive`) and markdown document rendering.
- Deterministic compliance engine checking RFC 5322 commit trailers and accidental AI assistant workspace leaks.
