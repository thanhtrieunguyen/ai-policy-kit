# AI Policy: NetBSD

- **Project**: NetBSD
- **Ecosystem / Category**: Operating System / BSD Ecosystem
- **Source URL**: https://www.netbsd.org/developers/commit-guidelines.html
- **Reference Document**: NetBSD Commit Guidelines, Section "Tainted Code"
- **Primary Stance**: Forbidden

## Verbatim Policy Text

> "Code generated by a large language model or similar technology, such as GitHub/Microsoft's Copilot, OpenAI's ChatGPT, or Facebook/Meta's Code Llama, is presumed to be tainted code, and must not be committed without prior written approval by core.
>
> The legal status of code generated by such tools is unclear with respect to copyright licensing and fair use doctrine. To protect the integrity and legal cleanliness of the NetBSD source tree, such code must be excluded."

## 4-Dimension Breakdown

### 1. Usage Regulations
- **Overall Level**: `forbidden`
- **Scope**: Source code, kernel drivers, system utilities, build scripts.
- **Exceptions**: Explicit written approval from the NetBSD Core Team prior to committing.

### 2. Disclosure Requirements
- **Mandatory Disclosure**: Mandatory written petition to NetBSD Core Team prior to committing any AI-assisted code.
- **Attribution / Commit Trailer**: None recognized without prior written Core approval.

### 3. Comprehension & Accountability
- **Human Comprehension**: Required. Committers bear strict responsibility for legal cleanliness of the repository.
- **Legal Accountability**: Absolute copyright defense. Presumption of "tainted code" due to unknown copyright licensing status of training datasets.

### 4. Review & Issue Rules
- **Automated PRs / Issues**: Banned. Unsolicited automated patches are rejected.
- **Automated Reviews**: Not permitted.
- **Triage Action**: Patches suspected of containing AI-generated code without Core approval are reverted immediately.
