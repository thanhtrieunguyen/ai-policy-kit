# AI Policy: Godot Engine

- **Project**: Godot Engine
- **Ecosystem / Category**: Game Development Engine / C++ & GDScript
- **Source URL**: https://godotengine.org/article/contribution-policy-2026/
- **Reference Document**: Godot Contribution Policy & AI Stance
- **Primary Stance**: Restricted

## Verbatim Policy Text

> "The use of autonomous AI agents to submit pull requests or fully generate unvetted code ('vibe coding') is strictly prohibited, with violations resulting in an automatic ban from the repository.
>
> AI must not be used to author substantial pieces of code. Code authoring decisions (architecture, algorithms, placement) must be made by humans.
>
> AI tools are only permissible for minor, menial tasks such as code completion, regex generation, or find-and-replace.
>
> If a contributor uses AI in any capacity, they MUST disclose which parts of the submission were not fully authored by them in the PR description.
>
> AI-generated text is prohibited in all human-to-human communications (GitHub issues/PR discussions, RocketChat) out of respect for volunteer maintainers' time."

## 4-Dimension Breakdown

### 1. Usage Regulations
- **Overall Level**: `restricted`
- **Scope**: Menial tasks only (code completion, regex helpers); authoring substantial architecture or algorithm code via AI is prohibited.
- **Exceptions**: Vibe coding is strictly banned.

### 2. Disclosure Requirements
- **Mandatory Disclosure**: Required in the PR description, explicitly stating which sections of the PR received AI assistance.
- **Method**: PR description disclosure section.

### 3. Comprehension & Accountability
- **Human Comprehension**: Required. Human developers must make all design and placement decisions.
- **Enforcement**: Submitting unvetted AI-generated PRs results in immediate repository bans.

### 4. Review & Issue Rules
- **Automated PRs / Issues**: Autonomous agent PRs are banned on sight.
- **Human Communications**: AI-generated text is strictly banned in PR discussions, issue comments, and chat channels.
