# AI Policy: Gentoo Linux

- **Project**: Gentoo Linux
- **Ecosystem / Category**: Linux Distribution / Operating System
- **Source URL**: https://wiki.gentoo.org/wiki/Project:Council/AI_policy
- **Reference Document**: Gentoo Council Decision (March/April 2024), `Project:Council/AI policy`
- **Primary Stance**: Forbidden

## Verbatim Policy Text

> "It is expressly forbidden to contribute to Gentoo any content that has been created with the assistance of Natural Language Processing artificial intelligence tools.
>
> This policy applies to code, documentation, bug reports, security reports, pull requests, and forum posts.
>
> The Council reserves the right to revisit this policy if AI tooling advances to the point where copyright and quality concerns are satisfactorily resolved."

## 4-Dimension Breakdown

### 1. Usage Regulations
- **Overall Level**: `forbidden`
- **Scope**: Code, documentation, tests, bug reports, pull requests, commit messages, forum discussions.
- **Exceptions**: Revisit clause reserved for Gentoo Council if copyright and quality issues are resolved.

### 2. Disclosure Requirements
- **Mandatory Disclosure**: N/A (AI-generated contributions are forbidden in their entirety).
- **Attribution / Commit Trailer**: Not permitted.

### 3. Comprehension & Accountability
- **Human Comprehension**: Required. Complete prohibition is driven by the fact that AI models generate plausibly-looking but subtly flawed code that contributors cannot properly explain or verify.
- **Legal Accountability**: Strict compliance with Gentoo copyright policies and avoidance of copyright infringement from scraped training datasets.

### 4. Review & Issue Rules
- **Automated PRs / Issues**: Strictly forbidden.
- **Automated Reviews**: Forbidden.
- **Forums & Discussions**: NLP AI generation is prohibited in Bugzilla, forum posts, and developer communication channels.
