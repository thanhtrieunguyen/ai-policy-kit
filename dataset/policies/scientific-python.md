# AI Policy: Scientific Python (SciPy / SymPy / NumPy)

- **Project**: Scientific Python Ecosystem (SciPy / SymPy / NumPy)
- **Ecosystem / Category**: Scientific Computing / Python Ecosystem
- **Source URL**: https://docs.scipy.org/doc/scipy/dev/conduct/ai_policy.html
- **Reference Document**: SciPy AI Policy (modeled on SymPy Developer Guidelines / SPE 008)
- **Primary Stance**: Restricted

## Verbatim Policy Text

> "Contributors bear full responsibility for any code or content they submit to SciPy repositories, regardless of whether it was written manually or generated using AI.
>
> Contributors must fully understand and be able to explain any code they submit, as well as related existing code. Submitting a patch or code snippet that a contributor does not understand or cannot support is unacceptable.
>
> Pull requests deemed to be low-quality or fully/mostly generated by AI without proper oversight or understanding can be rejected to avoid wasting maintainers' and developers' time."

## 4-Dimension Breakdown

### 1. Usage Regulations
- **Overall Level**: `restricted`
- **Scope**: Source code algorithms, numerical implementations, benchmarks, documentation, tests.
- **Exceptions**: Permitted as personal development aid; automated PR dumps are strictly rejected.

### 2. Disclosure Requirements
- **Mandatory Disclosure**: Expected in PR descriptions and checklist. Contributors must state whether generative tools were used.
- **Method**: PR template checklist and markdown explanation.

### 3. Comprehension & Accountability
- **Human Comprehension**: Absolute requirement. Contributors must understand and explain mathematical, algorithmic, and numerical stability implications.
- **Legal Accountability**: Human author takes full responsibility under BSD-3-Clause license terms.

### 4. Review & Issue Rules
- **Automated PRs / Issues**: Low-quality, bulk-generated AI pull requests are summarily closed without in-depth review.
- **Automated Reviews**: Prohibited. Maintainer review requires human verification of mathematical rigor.
