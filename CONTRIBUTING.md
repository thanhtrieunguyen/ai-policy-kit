# Contributing to ai-policy-kit

Thank you for your interest in contributing to `ai-policy-kit`!

## Code of Conduct & Values

1. **Deterministic & Practical:** We prioritize clear, deterministic checks over probabilistic AI guessing tools.
2. **Respect for Maintainers & Contributors:** Tools should help maintainers save review time without creating hostile hurdles for human developers.

## Development Workflow

1. Fork the repository and clone it locally.
2. Create a feature branch: `git checkout -b feat/your-feature-name`.
3. Commit your changes with clear semantic commit messages.
4. Ensure all tests and linting pass.
5. Push to your fork and submit a Pull Request.

## AI Usage Disclosure

When contributing to this repository, please disclose if AI tools were used during research, code generation, or testing. Contributors are expected to fully understand and take responsibility for any code submitted.
